# Моделийн сургалт

Камерын бодит зургаар каск, ажлын хувцсыг таних моделийг сайжруулна. Бүх зүйл **энэ хавтсанд** байна, веб дээр
**Сургалт** цэснээс (зөвхөн ADMIN) удирдана.

```
training/
  datasets/raw/          цуглуулсан зураг (.jpg)           ← git-д ОРОХГҮЙ (царай орсон)
  datasets/labels_auto/  цуглуулах үеийн AI-ийн санал      (шошгололтын эхлэл)
  datasets/labels/       ТАНЫ баталсан шошго (YOLO формат) (файл байгаа = шошглогдсон)
  models/base-n.pt, base-s.pt     суурь жин (COCO, YOLO26n/s)
  models/ppe-trained-<цаг>.onnx   сургасан модель
  runs/                  сургалтын лог, төлөв, түр өгөгдөл
  train.py, dataset_split.py      сургалтын скриптүүд
```

## Урсгал
1. **Цуглуулалт** — Сургалт → Цуглуулалт → асаана. AI service ажиллаж буй камеруудаас хүн харагдахад N секунд тутам,
   хоосон үед 5 дахин ховор зураг хадгална (дээд хязгаар 5000). Анхдагчаар УНТАРСАН.
2. **Шошглох** — Сургалт → Шошглох. Зураг дээр чирж хайрцаг зурна. Товчлуур: `1–5` ангилал, `S`/`Enter` хадгалаад дараагийн,
   `Delete` хайрцаг устгах, `←/→` зураг солих. Хайрцгийг чирж зөөнө, булангаас размер өөрчилнө.
   - **Хүн** — хүний бүх бие
   - **Каск** — зөвхөн каск; **Каскгүй толгой** — каск өмсөөгүй хүний толгой
   - **Ажлын хувцас** — ажлын хувцастай их бие; **Ажлын хувцасгүй** — энгийн хувцастай их бие
   - Юу ч харагдахгүй зураг: «Юу ч байхгүй» (хоосон шошготой сөрөг жишээ — худал дохиог бууруулна)
   - «AI санал» тэмдэгтэй зургийн хайрцгийг ЗААВАЛ шалгаж засна: одоогийн модель ажлын хувцсыг буруу таньдаг тул шууд
     батлах нь алдааг давтаж сургана.
3. **Сургах** — Сургалт → Сургах (≥ 30 шошглосон зураг). Явц, лог, төгсгөлд test үнэлгээ гарна.

## Үнэлгээ ба идэвхжүүлэх
Зургуудыг камерын дараалсан блокоор train 70% / val 20% / test 10% болгон хуваана (санамсаргүй биш — ойролцоо frame train болон
test-д давхар орж үнэлгээг хуурамч өндөр харуулахаас сэргийлнэ). Тайлан нь **test** дээрх анги бүрийн precision / recall / mAP50.

Идэвхжүүлэх: `ai-service/.env` дотор `MODEL_PATH=../training/models/ppe-trained-<цаг>.onnx`, `CLASS_MAPPING=` (хоосон),
`worker`-ийг дахин асаана. Муу гарвал `MODEL_PATH=./models/ppe-custom.onnx` болгож буцаана (хуучин модель устахгүй).

## Анхаарах
- Суурь жин нь ерөнхий COCO модель тул **цөөн зургаар сургавал одоогийн (`ppe-custom`) моделоос муу гарч болно**.
  300+ янз бүрийн зураг (гэрэл, өнцөг, хувцастай/хувцасгүй хүн, каскгүй толгой) шаардлагатай. Test үнэлгээгээр заавал шалгана.
- Хэрэв `ppe-custom`-ийн анхны `.pt` файл танд байвал `models/base-n.pt` болгож солино — тэр нь хамгийн сайн суурь.
- Сургалт интернэтээс юу ч татахгүй, ultralytics-ийн статистик илгээлт унтраалттай.
- Гараар: `cd training && ../ai-service/.venv/bin/python train.py --base models/base-n.pt --epochs 40`
- Тест: `cd training && ../ai-service/.venv/bin/python -m pytest tests`
